🖥 Platform & Environment Used

The tasks were performed using the following environment:

Operating System: Windows 10

Programming Language: Python 3.x

IDE / Code Editor: Visual Studio Code

Libraries Used: OpenCV, NumPy, Matplotlib

⚙ Installation Guide
1️⃣ How to Install Python
Step 1: Download Python

Visit the official website: https://www.python.org

Click on Download Python (latest version)

Step 2: Install Python

Run the installer

✅ Check “Add Python to PATH”

Click Install Now

Step 3: Verify Installation

Open Command Prompt and run:

python --version

If version appears, Python is successfully installed.

2️⃣ How to Install Visual Studio Code
Step 1: Download VS Code

Visit: https://code.visualstudio.com

Download for Windows

Step 2: Install

Run installer

Select:

✅ Add to PATH

✅ Add "Open with Code" option

Click Install

Step 3: Install Python Extension

Open VS Code

Go to Extensions (Ctrl + Shift + X)

Search Python

Install the official Python extension by Microsoft

3️⃣ Install Required Python Libraries

Open terminal in VS Code and run:

pip install opencv-python
pip install numpy
pip install matplotlib
▶ How to Run the Project

Open project folder in VS Code

Open the Python file

Run using terminal:

python filename.py
